# 流感高发季患儿增多 ，市妇幼保健院多措并举应对儿童就诊高峰

> 更新时间：2026-09-16 (UTC+8)

入冬以来，随着天气不断转冷，儿童传染病、呼吸道传染病和季节性流行病进入高发期。从11月下旬开始，市妇幼保健院门、急诊就诊人数均明显增加。特别是近两周以来，儿科及呼吸内科门、急诊量剧增。

为更好地应对季节性疾病高发期，进一步满足患者“就诊时段差异化”的需求，市妇幼保健院高度重视此情况，合理调配资源，强化门急诊管理，优化服务流程，协调住院病房医生支援门急诊，输液大厅实行弹性值班，增加护理人员，尽可能为患者提供便捷的服务，确保就诊安全。

走进市妇幼保健院门诊大厅，诊区里虽然人流密集，但接诊井然有序，所有的医务人员都在有条不紊的忙碌着。在市妇幼保健院儿科一病区，所有医务人员都在加班加点的工作，每天早上七点半就来到工作岗位，甚至是处于哺乳假期的护士都主动放弃早晨哺乳时间来医院帮忙，中午经常是忙到一点多才能吃上午饭。

据了解，整个儿一病区内总共有33张床，都已经住满，但是依然满足不了患者需求。平均每天该病区都有近50位患儿在院。为了让患儿能够及时就医，便在医院后勤部门的协助下，在走廊内临时增加床位。到了冬天气温低，儿科一病区护士长章媛担心走廊太冷患儿受不住，就在每间病房内临时增添了一张床位，希望患儿能够住的稍微舒服一点。但是在增添了15张临时床位后，病区内床位依旧紧张。入冬以后，其他儿科病区情况也大致如此。

   “每年冬季都是流感高发季，今年尤为突出，患儿比平时增加了一倍以上。我们所有医生护士都投入诊疗，所有诊室都是满负荷运转。”市妇幼保健院儿科一病区主任林泳介绍道。今冬流感病毒比往年同期来得凶猛，除了合胞病毒、乙型流感较流行外，还有一些其他病毒，儿童就诊量剧增。林泳提醒家长做好相关防护，家里经常通风，平时应让孩子清淡饮食、多喝水，一旦出现感冒症状及时居家休息，避免带病上学。
