# 移植后的注意事项

> 更新时间：2026-09-16 (UTC+8)

许多准妈妈在移植后都变得小心翼翼，恨不能一步都不要走，感觉自己成了一个易碎的花瓶，其实大可不必。下面我们就来谈谈移植以后什么需要注意，什么不需要格外在意。

**需要特别注意**

1. 遵医嘱用药，千万不要停，也千万不要忘。（自己定个小闹钟就不会忘啦）

2. 移植后半月内不要同房，不要游泳，不要泡温泉，不要洗盆浴（但是可以洗淋浴哦，不然那味道就不美啦）。

。

**需要注意******

1. 不要太过劳累，能不操的心就不操心，放松自己最重要。

2. 因为此时胃肠道比较弱，所以不要吃生冷辛辣刺激的食物以防引起腹泻；便秘者可以多吃高蛋白高纤维食物促进胃肠蠕动。

3. 不要去人员密集场所以防传染病发生，注意不要着凉以防感冒、发烧、拉肚子，如果出现上述症状要及时就医，按孕妇管理用药，不可自己在家中随意用药。

**不需要格外在意******

1. 不用天天卧床休息，应正常生活。

2. 可以上下楼梯、骑电车、坐车（掌握在不劳累的程度）。

3. 可以正常上班。

4. 可以外出旅游散心，减轻心理压力。
